# Read the last group first. Search engines are NOT disallowed here, and that is
# deliberate: every response carries X-Robots-Tag: noindex, nofollow, noarchive,
# nosnippet, noimageindex, and a crawler has to FETCH the page to see it. A
# blanket Disallow would stop it reading the header, and a URL that is merely
# uncrawled can still be listed from a link elsewhere - so blocking the crawl
# would put the address back into results, not keep it out. The header does the
# work; this file handles what the header cannot.
#
# What the header cannot do is opt out of model training. noindex says "do not
# list me"; it says nothing about ingestion, and the crawlers below take
# robots.txt as the opt-out signal. Hence the split.
